## 🏗️ 技术架构

### 技术栈
- **桌面框架**: Tauri 2.0
- **前端**: React 18 + TypeScript
- **后端**: Rust
- **状态管理**: React Hooks
- **UI 渲染**: Canvas API
- **构建工具**: Vite
- **测试框架**: 
  - Rust: proptest
  - TypeScript: vitest + fast-check + @testing-library/react

## 🎮 用户体验

### 游戏流程
1. 启动应用程序
2. 选择游戏类型（象棋或军棋）
3. 点击棋子查看合法移动
4. 点击目标位置移动棋子
5. AI 自动响应
6. 游戏结束时显示结果
7. 可以悔棋、重新开始或返回主菜单
