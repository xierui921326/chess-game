## 🛠️ 维护说明

### 添加新文档
新的项目文档应该放在本目录下，并更新本 README.md 文件。

### 文档命名规范
- 使用大写字母和下划线：`PROJECT_SUMMARY.md`
- 使用描述性的名称
- 保持简洁明了

### 文档更新
当项目有重大更新时，应该：
1. 更新相关文档
2. 在 `CHANGELOG.md` 中记录变更
3. 如有必要，更新根目录的 `README.md`

## 📝 文档格式

所有文档使用 Markdown 格式，遵循以下规范：
- 使用中文（简体）
- 代码使用英文
- 清晰的标题层级
- 适当的代码块和列表
- 必要的链接和引用
