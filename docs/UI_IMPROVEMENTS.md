# UI 改进记录

## 2026-02-03 - 棋盘显示优化

### 问题描述
1. 页面无法在一屏内展示所有功能
2. 象棋的楚河汉界位置不正确
3. 军棋的棋盘绘制有问题（缺少铁路线和营地标记）

### 解决方案

#### 1. 尺寸调整（适应一屏显示）
**文件**: `src/components/BoardRenderer.tsx`
- `CELL_SIZE`: 60 → 45（减小 25%）
- `PADDING`: 40 → 30（减小 25%）
- `PIECE_RADIUS`: 25 → 18（减小 28%）
- 字体大小: 16px → 14px

**文件**: `src/components/GameBoard.css`
- 添加 `max-height: 100vh` 和 `overflow-y: auto`
- 标题字体: 2rem → 1.5rem
- 减小所有按钮和状态栏的 padding
- 优化间距以适应更紧凑的布局

#### 2. 象棋楚河汉界修复
**文件**: `src/components/BoardRenderer.tsx`
- 修正楚河汉界位置：现在正确显示在第 4-5 行之间
- 修复竖线绘制：中间断开以显示楚河汉界
  - 上半部分：0-4 行
  - 下半部分：5-9 行
- 使用 SimSun 字体显示"楚河"和"汉界"文字

#### 3. 军棋棋盘完善
**文件**: `src/components/BoardRenderer.tsx`

新增功能：
- **铁路线**（粗线显示）
  - 横向铁路：第 1, 5, 6, 10 行
  - 竖向铁路：左右两侧（第 0 和第 4 列）
- **营地标记**（用小圆圈标记）
  - 黑方营地：(2,1), (2,3), (3,2)
  - 红方营地：(8,2), (9,1), (9,3)
- **行营连线**
  - 黑方行营三角形连线
  - 红方行营三角形连线

### 技术细节

#### 绘制顺序
1. 背景
2. 网格线
3. 特殊标记（九宫格/铁路线/营地）
4. 合法移动提示
5. 选中棋子高亮
6. 棋子

#### 样式优化
- 使用 `rgba` 颜色实现半透明效果
- 营地使用灰色半透明圆圈
- 铁路线使用较粗的线条（lineWidth: 2）
- 保持一致的视觉层次
